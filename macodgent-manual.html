1. mc_mode

Meet the data
mc_mode() is a teaching implementation of the mode, which base R does Not provide. It returns *every* value tied for the highest frequency, so Data with several modes is handled correctly instead of returning only one.

Usage

mc_mode(x, na.rm = TRUE)

Details

Purpose: find the value(s) with the highest frequency (the mode). Base R has No built-in mode function, so this is a teaching-oriented reimplementation. Arguments: x accepts a numeric or factor vector; na.rm controls whether Missing values are removed before counting (default TRUE, so NAs are excluded From the frequency tally). Result: returns every value tied for the highest frequency, so multimodal Data is handled naturally - a bimodal distribution returns both modes; the Return type matches the input (numeric input yields a numeric vector). Note: if every value occurs exactly once, all values are treated as modes and Returned as-is, which is usually meaningless; run mc_inspect() first to Understand the distribution. Returns NULL when all observations are missing.

Arguments

xA numeric or factor vector.
na.rmRemove missing values first? Default TRUE (logical).

Value

A vector of all mode(s), coerced back to the input type; NULL when There are no non-missing values.

Examples

# low birthweight study dataset (birthwt, MASS)
birthwt <- MASS::birthwt
mc_mode(factor(birthwt$race)) # most common race category (1 = white)
mc_mode(factor(birthwt$smoke)) # mode of smoking status (0 = non-smoker)
mc_mode(c(NA, NA, 1, 2), na.rm = FALSE) # returns "NA" when NA present

2. mc_inspect

Meet the data
One row per column: the column class, number of observations n, Count of missing values n_missing, missing percentage pct_missing, and Number of unique values n_unique. Handy for a quick data-quality check Before modelling.

Usage

mc_inspect(.data)

Details

Purpose: a quick pre-modelling data-quality check; for each column it reports The type, number of observations, number of missing values, missing Percentage and number of unique values. Arguments:.data is a data.frame or tibble; no other arguments. Result: returns a data.frame with one row per input column. Columns: variable (column name), class (type), n (valid observations), n_missing (missing Count), pct_missing (missing percentage), n_unique (number of unique values). Note: n is the count of valid (non-missing) observations, so n + n_missing Equals the column's total length, and the missing percentage is computed Against that total length. This is the first "health check" of the Preprocessing pipeline - run it before any cleaning or modelling.

Arguments

.dataA data.frame or tibble.

Value

A data.frame with those six columns, one row per input column.

Examples

# data-quality check on the birthwt data frame (try injecting
# missing values to practice)
birthwt <- MASS::birthwt
mc_inspect(birthwt[, c("age", "lwt", "bwt", "smoke", "low")])

4. mc_palette

Meet the data
Supplies a set of stable brand anchor colours (hex) and, instead of a static Vector, **linearly interpolates** between anchors to generate any number of Transition colours (a continuous gradient or a discrete ramp). Returns a named Character vector usable with ggplot2::scale_color_manual() / scale_fill_manual().

Usage

mc_palette(n = NULL, type = c("brand", "gradient", "discrete"))

Details

Purpose: returns the brand anchor colours to keep plotting colours Consistent; when the number of categories exceeds 6, it interpolates between Anchors to generate the required number of colours, avoiding manual colour Picking. Method (original): internally it parses "#RRGGBB" into a 0-255 RGB triplet (.hex_to_rgb), performs linear interpolation between anchor colours by Position (.interp_palette), then converts the result back to hex (.rgb_to_hex); the whole process uses no palette package. Arguments: n is the number of colours to generate; NULL (default) returns the Six fixed brand colours. type selects "brand" (default, six discrete brand Colours), "gradient" (continuous gradient between brand colours, default 100 Colours), or "discrete" (a discrete ramp interpolated over the brand Colours). Result: by default returns a named character vector with the six brand Colours: primary (blue), secondary (purple), accent (green), warn (red), Info (cyan), muted (grey). When n is given, returns a colour vector of length N (gradient is unnamed by default; discrete/brand keep anchor names). Note: colours are generated purely algorithmically with no dependence on Data; interpolation is in linear RGB space - switch to HCL space later if a More perceptually uniform ramp is needed. Often paired with mc_theme() for Style-consistent report figures.

Arguments

nThe number of colours to generate; NULL = the six fixed brand Colours.
typePalette type: "brand", "gradient" or "discrete".

Value

A named character vector of the six brand colours by default, or a Vector of length n.

Examples

pal <- mc_palette() # default: six brand colours
print(pal)
grad <- mc_palette(n = 20, type = "gradient") # 20-colour continuous gradient
print(head(grad))
library(ggplot2)
df <- data.frame(name = factor(names(pal), names(pal)), col = pal)
p <- ggplot(df, aes(name, fill = name)) + geom_bar() +
scale_fill_manual(values = pal) + theme_void()
print(p)

5. mc_impute_knn

Preprocessing
Imputes only numeric columns Using standardised Euclidean distance; missing values in non-numeric columns Are left untouched with a warning. No extra dependency is required.

Usage

mc_impute_knn(.data, k = 5)

Details

Purpose: Impute missing values in numeric columns using K-nearest neighbours, Suitable when missingness is low and variables are correlated. Method: Only numeric columns are processed. Columns are standardised (mean-centred, divided by SD), then for each missing point the k nearest Non-missing observations are found by Euclidean distance and their mean is Used to impute; columns with zero SD fall back to column-mean imputation. Missing values in non-numeric columns are left untouched with a warning. Arguments: .data is a data.frame; k is the number of neighbours, default 5. Result: Returns an imputed data.frame with the same structure as the input. Note: KNN is sensitive to scale, so standardisation is done internally; However, if columns differ greatly in range, it is still recommended to run mc_scale() first. Categorical variables are not used in KNN and must be Handled separately (e.g. mode imputation or category merging).

Arguments

.dataA data.frame.
kNumber of neighbours; default 5.

Value

The imputed data.frame (same structure as the input).

Examples

# demonstrating kNN missing-value imputation with iris
data(iris)
set.seed(105)
iris_na <- iris
iris_na$Sepal.Length[sample(150, 15)] <- NA
iris_na$Sepal.Width[sample(150, 15)] <- NA
head(mc_impute_knn(iris_na, k = 3))

6. mc_impute_mice

Preprocessing
Requires the mice package (Suggests). On top of the MICE engine, it **adds an original per-variable imputation diagnostic**.

Usage

mc_impute_mice(.data, m = 5, method = NULL, ...)

Details

Purpose: Use multiple imputation by chained equations (MICE) to handle Missingness, suitable when the missingness mechanism is complex and you want To retain uncertainty; it also provides a quantitative per-column imputation Diagnostic afterwards. Dependency: Requires the mice package (Suggests); an informative error is Raised if it is not installed. Method: For each variable with missingness, related variables are used as Predictors in an iterative model that generates multiple complete datasets, Preserving the uncertainty due to missingness. Arguments: .data is a data.frame; m is the number of imputations (datasets generated), default 5; method of NULL means automatic selection; ... is passed to mice::mice(). Result: Returns a list containing mids (the raw multiple-imputation object For further analysis), long (the long table from Mice::complete(action = "long")), and summary - an **original diagnostic Table**: per variable it gives n_missing_original (original missing count), n_imputed (count of imputed observations), and pct_imputed (imputation Proportion). Note: Analysis after multiple imputation should not rely on a single dataset; Instead use the mids object with downstream functions supporting mice (e.g. with()/pool()) to pool results. The summary is only for quickly Checking which variables were imputed and by how much, and does not represent Imputation quality itself.

Arguments

.dataA data.frame.
mNumber of imputations; default 5.
methodMethod passed to mice(); NULL = automatic.
...Other arguments passed to mice::mice().

Value

A list with mids, long, and summary: mids is The raw mids object, long is the imputed long table (from mice::complete(action = "long")), and summary is the per-variable Imputation diagnostic table.

Examples

\dontrun{
# multiple imputation by chained equations (mICE) with per-variable diagnostic
set.seed(106)
n <- 44
df <- data.frame(
age = c(rnorm(n - 4, 50), NA, NA, rnorm(2, 55)),
bili = c(NA, rnorm(n - 4, 1.2), NA, rnorm(2, 1.5)),
chol = rnorm(n, 200, 40), stringsAsFactors = FALSE)
res <- mc_impute_mice(df, m = 3)
head(res$long)
print(res$summary) # original: per-variable imputation diagnostic

8. mc_scale

Preprocessing

Usage

Value

The scaled data.frame; only numeric columns are replaced.

Examples

9. mc_wide_long

Preprocessing
Pivots the specified measure columns of a wide table into a long layout. Implemented natively in base R with **no external pivoting dependency**.

Usage

mc_wide_long(.data,
             id_cols,
             measure_vars,
             name_to = "variable",
             value_to = "value")

Details

Purpose: Convert a wide table (multiple measurements of one subject in Different columns) to a long table (one row per measurement); a core step in Data processing. Method (original, native implementation): First verify that id_cols and measure_vars exist in the data.frame; then for each measure column, replicate And stack the identifier columns by the number of measure columns, and merge Each measure column name as the "variable" and its values as the "value", Producing a tidy long table. Uses only base R with no external dependency. Arguments: .data is a data.frame; id_cols are the identifier columns to Keep (e.g. ID, group); measure_vars are the measure columns to lengthen; name_to/value_to are the output column names for "variable" and "value", Defaulting to variable / value. Result: Returns a long-format data.frame. Note: After conversion, rows = original rows x number of measure columns; this Is the inverse of mc_long_wide(). If measure columns carry time suffixes (e.g. t1/t2/t3), the result is a tidy "time-value" pair of columns, convenient For repeated-measures analysis. Identifier columns that are factors are Preserved as factors; measure columns should share a common type, otherwise The "value" column is coerced to a common type.

Arguments

.dataA data.frame.
id_colsIdentifier columns to keep.
measure_varsMeasured columns to pivot longer.
name_toOutput name column; default "variable".
value_toOutput value column; default "value".

Value

The long data.frame.

Examples

# convert wide table of longitudinal blood-pressure measurements to long (t1/t2/t3 visits)
wide <- data.frame(id = 1:4,
t1 = rnorm(4, 120), t2 = rnorm(4, 122), t3 = rnorm(4, 118))
mc_wide_long(wide, id_cols = "id", measure_vars = c("t1", "t2", "t3"))

13. mc_var_test

Quantitative description
Bartlett, Fligner-Killeen, and Levene (mean-deviation method). Returns the Test name, statistic and p-value.

Usage

mc_var_test(x, g, method = c("bartlett", "fligner", "levene"))

Note: if variances are unequal (small p), use Welch correction (e.g. mc_ttest Defaults to Welch for two samples) or a non-parametric method instead of the Standard t-test/ANOVA. Bartlett relies strongly on normality; for non-normal Data prefer Levene or Fligner.

Arguments

xNumeric vector.
gA grouping factor.
method"bartlett" (default) / "fligner" / "levene" (test method).

Value

A data.frame with columns test, statistic, p.value.

Examples

# test variance homogeneity of birth weight across races (race)
birthwt <- MASS::birthwt
mc_var_test(birthwt$bwt, birthwt$race, method = "bartlett")
mc_var_test(birthwt$bwt, birthwt$race, method = "levene")

14. mc_ttest

Quantitative description
One-sample, independent two-sample, and paired T-tests through a single entry point.

Usage

mc_ttest(x,
         y = NULL,
         paired = FALSE,
         mu = 0,
         conf = 0.95,
         alternative = "two.sided")

Details

Purpose: a unified entry point for t-tests covering three common cases: One-sample (vs a known constant), independent two-sample, and paired. Methods: two independent samples use Welch's corrected t-test by default (no Equal-variance assumption), closer to practice; can switch to Student's t. Arguments: x is the first group or one-sample vector; y is the second Vector (for independent/paired; left NULL for one-sample); paired = TRUE Runs a paired t-test; mu is the reference value for the one-sample test, Default 0; conf/alternative control confidence level and the alternative Direction. Result: returns the mean difference (or sample mean), standard error, t Statistic, degrees of freedom, p-value and confidence interval. Note: paired tests require x, y to be paired (e.g. same person measured Before/after); using an independent test when groups are not independent Understates error. For clearly skewed or small samples, consider mc_nonparam()'s Wilcoxon test.

Arguments

xNumeric vector.
yA second vector (for independent/paired); NULL for one-sample.
pairedLogical; paired? default FALSE.
muHypothesised mean for one-sample; default 0.
confConfidence level; default 0.95.
alternative"two.sided" (default) / "less" / "greater".

Value

A data.frame with columns method, estimate, conf.low, conf.high, statistic, p.value.

Examples

#
birthwt <- MASS::birthwt
# one-sample: is the average birth weight equal to 3000 g?
mc_ttest(birthwt$bwt, mu = 3000)
# independent two-sample (welch correction): smoking vs non-smoking mothers' birth weight
mc_ttest(birthwt$bwt[birthwt$smoke == 1], birthwt$bwt[birthwt$smoke == 0])

16. mc_nonparam

Quantitative description
Wilcoxon Rank-sum (two groups) or Kruskal-Wallis (multiple groups). Returns the test Name, statistic and p-value.

Usage

mc_nonparam(x, g, method = c("wilcoxon", "kruskal"))

Arguments

xNumeric vector.
gGrouping vector/factor.
method"wilcoxon" (default) or "kruskal" (test method).

Value

A data.frame with columns test, statistic, p.value.

Examples

# birth weight by smoking status (two-group wilcoxon) and race (multi-group kruskal-wallis)
birthwt <- MASS::birthwt
mc_nonparam(birthwt$bwt, birthwt$smoke, method = "wilcoxon")
mc_nonparam(birthwt$bwt, factor(birthwt$race), method = "kruskal")

formulaA model formula, e.g. y ~ x1 + x2.
ncompNumber of principal components; NULL = auto-select by CV.
kCV folds; default 5.
seedRandom seed for CV.

Value

A list with chosen components, CV table, original-scale coefficients, Performance and the CV plot.

statusCompeting-risk status variable name.

causeEvent type of interest; default 1.
