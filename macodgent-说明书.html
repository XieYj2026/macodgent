1. mc_gam

用途：拟合广义可加模型（GAM），在保持线性模型可解释性的同时，允许自变量以平滑（非线性）形式进入模型，自动捕捉曲线关系。 方法：基于 mgcv 包的 gam()，用样条（如 s(x)）表示平滑项，自动选择平滑自由度并给出显著性。 参数：data 为数据框；formula 形如 y ~ s(x1) + x2，其中 s() 包裹的项为平滑项，其余为线性项。 结果：返回列表，含 model（gam 对象，可用 plot() 看平滑曲线）、terms（各平滑项的自由度 edf、参考自由度、F 值与 p 值，用于判断该变量是否具非线性效应）。 注意：edf 接近 1 且 p 不显著，说明该变量近似线性、无需平滑；edf 很大可能过拟合。平滑项需要足够样本量才能稳定估计。依赖 mgcv（Suggests）。想看效应图用 plot(res$model, pages=1, shade=TRUE)。

示例代码 / Example

# 第 7 章：用 GAM 刻画孕期体重(lwt)对出生体重的非线性效应
birthwt &lt;- MASS::birthwt
res &lt;- mc_gam(birthwt, bwt ~ s(lwt) + smoke)
cat("平滑项表 / smooth terms:\n")
print(as.data.frame(res$terms), row.names = FALSE)

运行结果 / Output

2. mc_lasso

用途：用 Lasso（L1 正则化）做回归与变量选择，在高维或共线性数据中自动把不重要变量的系数压缩为 0，实现「内嵌式」筛选。 方法：基于 glmnet 包，alpha=1 即 Lasso；用 k 折交叉验证（默认 10 折）选择最优惩罚强度 λ。 参数：data 为数据框；x 为自变量列名向量；y 为因变量列名；nfolds 为 CV 折数（默认 10）；family 默认 gaussian（连续结局），也可用于 binomial 等。 结果：返回含 coefficients（非零系数表，被压缩为 0 的变量不出现）的列表。 注意：Lasso 给出的系数是有偏的（被整体收缩），适合预测与筛选，不适合直接做统计推断。当多个变量高度相关时，Lasso 会随机挑其中一个、其余置零。λ 越大收缩越强；可用 cv.glmnet 的 lambda.min/lambda.1se 调参。依赖 glmnet（Suggests）。

示例代码 / Example

# 第 7 章：用 Lasso 在 mtcars 的全部预测变量中做变量选择（mpg ~ .）
xvars &lt;- setdiff(names(mtcars), "mpg")
mc_lasso(mtcars, x = xvars, y = "mpg")$coefficients

3. mc_ridge

用途：用岭回归（L2 正则化）处理多重共线性，稳定系数估计，适合「变量都重要但不想丢弃任何一个」的场景。 方法：基于 glmnet 包，alpha=0 即岭回归；对所有系数做等比例收缩（不置零），保留全部变量。 参数：data 为数据框；x 为自变量列名向量；y 为因变量列名；nfolds 为 CV 折数（默认 10）；family 默认 gaussian。 结果：返回含 coefficients（被收缩但均非零的系数表）的列表。 注意：与 Lasso 不同，岭回归的系数永远不会精确为 0，因此不做变量选择、只做系数收缩。它对共线性稳健（把方差分摊到相关变量上），但解释时变量仍全部保留。λ 越大收缩越强。依赖 glmnet（Suggests）。

示例代码 / Example

# 第 7 章：岭回归处理 mtcars 预测变量的多重共线性
xvars &lt;- setdiff(names(mtcars), "mpg")
mc_ridge(mtcars, x = xvars, y = "mpg")$coefficients

4. mc_elastic_net

用途：用弹性网络（Elastic Net）兼顾 Lasso 的稀疏性与岭回归对共线性的稳健性，是二者之间的连续调节。 方法：基于 glmnet 包，alpha 在 0（纯岭）到 1（纯 Lasso）之间调节混合比例；alpha=0.5 是常用折中。 参数：data 为数据框；x 为自变量列名向量；y 为因变量列名；alpha 为混合参数（默认 0.5）；nfolds 为 CV 折数；family 默认 gaussian。 结果：返回含 coefficients（按所选 α 收缩后的系数表，部分可能为 0）的列表。 注意：当自变量成组高度相关时，弹性网络比 Lasso 更稳健——它会把整组相关变量一起保留或一起剔除，而非随机留一个。α 越接近 1 越偏向变量选择，越接近 0 越偏向系数收缩。依赖 glmnet（Suggests）。

示例代码 / Example

# 第 7 章：弹性网络（alpha = 0.5）兼顾变量选择与系数收缩
xvars &lt;- setdiff(names(mtcars), "mpg")
mc_elastic_net(mtcars, x = xvars, y = "mpg", alpha = 0.5)$coefficients

运行结果 / Output

5. mc_rcs

用途：用受限立方样条（RCS）刻画自变量与结局之间的非线性剂量-反应关系，并可视化曲线，是流行病学中呈现「暴露-效应」曲线的常用方法。 方法：自实现样条基（无额外依赖），在自变量两端做线性约束（「受限」），避免样条在边界处剧烈摆动；默认节点数 nk=3。 参数：data 为数据框；x 为自变量列名；y 为因变量列名；nk 为节点数（默认 3，越大越灵活）；knots 可手动指定节点位置（默认按分位数自动选取）；family 默认 gaussian，也支持 binomial（此时刻画对数发生比随 x 的变化）。 结果：返回列表，含 knots（节点位置）、coefficients（样条基系数）、plot（预测曲线图，ggplot 对象）。 注意：节点数越多曲线越曲折、越易过拟合；一般 3–5 个节点足够。RCS 不假设单调，能呈现「U 形」「倒 U 形」等复杂关系。绘制结果用 print(res$plot)。

示例代码 / Example

# 第 7 章：母亲年龄对低出生体重风险的「剂量-反应」曲线（非线性）
birthwt &lt;- MASS::birthwt
res &lt;- mc_rcs(birthwt, x = "age", y = "low", nk = 4, family = "binomial")
cat("节点位置 / knots:", round(res$knots, 2), "\n")
print(res$plot)

运行结果 / Output

节点位置 / knots: 14 19 21 24 28 45

6. mc_quantile_reg

用途：用分位数回归刻画自变量对结局不同分位点（如中位数、上下四分位）的影响，特别适合存在异方差或关注极端分位（如低收入、高死亡风险）的场景。 方法：基于 quantreg 包的 rq()，最小化加权的绝对残差，可同时估计多个分位点的系数。 参数：data 为数据框；formula 形如 y ~ x；taus 为要估计的分位点向量，默认 c(0.25, 0.5, 0.75)。 结果：返回各分位点系数的数据框（含截距与自变量斜率），可比较不同分位下斜率的差异。 注意：若 taus 上不同分位的自变量斜率明显不同（如异方差时），说明条件分布形态随 x 变化——这是普通均值回归（OLS）看不到的信息。分位数回归对异常值稳健。依赖 quantreg（Suggests）。

示例代码 / Example

# 第 7 章：出生体重的条件分位数回归（不同分位下孕期体重 lwt 的斜率）
birthwt &lt;- MASS::birthwt
mc_quantile_reg(birthwt, bwt ~ lwt + age, taus = c(0.25, 0.5, 0.75))

7. mc_pcr

用途：当预测变量高度相关（多重共线）时，用主成分回归稳定估计。 方法（自研）：① 对预测变量做标准化（中心化+缩放）；② PCA 得到互不相关的 主成分；③ 若未指定主成分数，用自研 k 折交叉验证按预测均方误差（MSE）选最优 个数；④ 以选出的主成分拟合线性回归；⑤ 将主成分系数反变换回原始变量尺度 （利用旋转矩阵与标准化参数）。 参数：\code{data} 为数据框；\code{formula} 形如 \code{y ~ x1 + x2 + ...}； \code{ncomp} 为主成分个数（NULL 时由 CV 自动选）；\code{k} 为交叉验证折数 （默认 5）；\code{seed} 为 CV 随机种子。 结果：返回列表——\code{best_ncomp}（选定主成分数）、\code{cv_table}（各候选 数的 CV-MSE）、\code{coef_original}（原始尺度系数+截距）、\code{performance} （R²/调整 R²/RMSE）、\code{plot}（CV-MSE 随主成分数变化图）、\code{fit} （最终 lm 对象）。 注意：PCR 对预测变量做了标准化，系数与标准化后的量纲相关；分类变量应先 哑变量化再纳入。本函数仅依赖基础 R，无需额外安装包。

示例代码 / Example

# 第 7 章 7.8 节：多个相关预测变量预测出生体重（主成分回归消除共线性）
# 注：PCR 要求全部预测变量为数值型，故不纳入分类变量 race（哑变量化另述）
birthwt &lt;- MASS::birthwt
bw &lt;- birthwt
res &lt;- mc_pcr(bw, bwt ~ age + lwt + smoke + ht + ui + ptl, k = 5, seed = 1)
res$best_ncomp

8. mc_nnet_reg

用途：用神经网络拟合预测变量与连续结局间的非线性关系。 依赖：需要 nnet 包（位于 Suggests）；未安装时给出明确提示。 方法：\code{nnet::nnet(y ~ ., linout = TRUE, size = hidden)}，隐藏层节点数由 \code{hidden} 控制；数据自动标准化以加快收敛。 参数：\code{data} 为数据框；\code{formula} 形如 \code{y ~ x1 + x2 + ...}； \code{hidden} 为隐藏层节点数（默认 5）；\code{maxit} 为最大迭代次数（默认 200）； \code{seed} 为随机种子。 结果：返回列表——\code{fit}（nnet 对象）、\code{predictions}（拟合值）、 \code{rmse}、\code{plot}（预测 vs 实测散点）。 注意：神经网络对尺度敏感，本函数内部对预测变量做了标准化；结果对随机初始化 敏感，建议设置 \code{seed} 以保证可复现。节点数过多易过拟合，可用 mc_model_compare() 或交叉验证比较不同结构。

9. mc_contingency

用途：构建分类变量的列联表并做独立性/关联检验，是分析分类变量关联的第一步，且覆盖 4.3 节要求的三种方法。 方法： \itemize{ \item \code{"chisq"}（默认）：对 2×2 及以上表做卡方独立性检验；\code{correct=TRUE} 时对 2×2 表加 Yates 连续性校正，防止小样本高估显著性。当表为 2×2 时，额外用 Fisher 精确法给出 OR 及其 95% CI。 \item \code{"fisher"}：对任意 r×c 表用 \code{stats::fisher.test} 做精确检验（适合小样本或期望频数过小的情形）。 \item \code{"cmh"}：需提供 \code{strata} 分层变量，构造三维列联表后用 \code{stats::mantelhaen.test} 做 Cochran-Mantel-Haenszel 检验，在控制分层因素后判断行-列关联是否仍然存在，并返回共同比值比（common OR）。 } 参数：.data 为数据框；row/col 为行、列变量名；correct 控制卡方连续性校正；method 选择检验类型；strata 为 CMH 所需的层变量名。 结果：返回列表，含 table（列联表，三维时分层展开）、test（检验数据框：test/statistic/df/p.value），并视方法附带 OR / commonOR。 注意：卡方检验要求期望频数不能过小（一般要求足够比例的格子期望 &gt;5），否则改用 \code{method="fisher"}。CMH 适用于存在混杂分层（如多中心研究）时估计「调整后的」关联。OR&gt;1 提示正关联；置信区间跨 1 表示关联不显著。

示例代码 / Example

# 第 4 章 4.3 节：以 birthwt 演示三种独立性检验
birthwt &lt;- MASS::birthwt

## ---- 卡方独立性检验（2x2 附 Fisher OR）----
res &lt;- mc_contingency(birthwt, row = "smoke", col = "low")
cat("---- 列联表 / table ----\n"); print(res$table)
cat("\n---- 卡方检验 / chi-square ----\n"); print(res$test, row.names = FALSE)
cat("\n---- 比值比 OR / odds ratio ----\n"); print(res$OR, row.names = FALSE)

## ---- Fisher 精确检验（小样本/期望频数过小时）----
res2 &lt;- mc_contingency(birthwt, row = "smoke", col = "low", method = "fisher")
print(res2$test, row.names = FALSE); print(res2$OR, row.names = FALSE)

## ---- CMH 分层检验：控制高血压(ht)后吸烟与低体重的共同 OR ----
res3 &lt;- mc_contingency(birthwt, row = "smoke", col = "low",
                       method = "cmh", strata = "ht")
cat("\n---- CMH 检验 / Cochran-Mantel-Haenszel ----\n")
print(res3$test, row.names = FALSE)
print(res3$commonOR, row.names = FALSE)

10. mc_corr

用途：计算变量间的相关系数，支持 Pearson（线性）与 Spearman（秩/单调），并可计算偏相关（控制混杂变量后）。 方法：pearson 衡量线性关联，假设近似正态；spearman 基于秩，对非线性单调关系与异常值更稳健；control 指定一个或多个控制变量，计算偏相关（剔除这些变量影响后的净相关）。 参数：.data 为数据框；vars 为参与相关的变量名向量；method 选择相关类型；control 为可选的控制变量名。 结果：返回相关矩阵（含相关系数），偏相关时返回控制后的矩阵。 注意：相关系数只衡量关联强度与方向，不等于因果；接近 0 不代表无关（可能是非线性）。Spearman 更适合 ordinal 数据或明显偏态。偏相关能帮助识别「虚假相关」（由共同混杂变量造成）。

示例代码 / Example

# 第 4 章 4.5 节：birthwt 中出生体重、孕期体重的相关（Spearman）
birthwt &lt;- MASS::birthwt
cat("==== Spearman 相关 / Spearman ====\n")
# 注：birthwt 含相同观测值（ties），cor.test 会以渐近法替代精确 p 值并提示，
# 属正常统计说明；此处抑制该提示以简化示例输出
suppressWarnings(print(mc_corr(birthwt, vars = c("bwt","lwt"), method = "spearman"),
                         row.names = FALSE))
cat("\n==== 控制母亲年龄后的偏相关 / partial on age ====\n")
print(mc_corr(birthwt, vars = c("bwt","lwt"), control = "age"),
      row.names = FALSE)

11. mc_tableone

用途：生成论文中常见的「Table 1」基线特征表，一行一个变量，按暴露/分组列展示，便于直接写进 manuscript。 方法：数值变量汇总为「均值 ± 标准差」（近似正态时）；分类变量汇总为频数与百分比。 参数：.data 为数据框；vars 为要纳入的变量名；group 为可选的分组列（如治疗组），此时按组分别汇总；digits 控制小数位数，默认 2。 结果：返回整齐的数据框，可直接 knitr::kable() 或 print() 成表。 注意：分组比较的 p 值通常不在此表内（可另行用 mc_ttest/mc_nonparam/mc_contingency 计算）。分类变量若水平过多会撑宽表格，建议先合并稀有类别。这是描述性表格，不替代统计推断。

示例代码 / Example

# 第 4 章：birthwt 基线特征表（按低出生体重 low 分组）
birthwt &lt;- MASS::birthwt
bw &lt;- birthwt
bw$race  &lt;- factor(bw$race, levels = 1:3, labels = c("白人","黑人","其他"))
bw$smoke &lt;- factor(bw$smoke, levels = 0:1, labels = c("否","是"))
bw$low   &lt;- factor(bw$low, levels = 0:1, labels = c("正常","低体重"))

14. mc_var_test

17. mc_nonparam

18. mc_linear

用途：拟合一元或多元线性回归，并自动产出可报告的系数表与诊断结果。 方法：以 \code{stats::lm} 做最小二乘拟合；在此之上自研实现三项诊断—— （1）\strong{自助法 CI}：对观测行做有放回重抽样、反复重拟合，取系数经验 分位数作为区间，不依赖任何正态假设（设置 \code{bootstrap &gt; 0} 开启）； （2）\strong{VIF}：对每个预测变量以其余预测变量做辅助线性回归，取 1/(1-R²) 作为该变量的方差膨胀因子，VIF&gt;5 通常提示多重共线性； （3）\strong{四张诊断图}：残差 vs 拟合（看非线性/异方差）、正态 Q-Q（看残差 正态性）、尺度-位置（看离散度是否随拟合值变化）、Cook 距离（看强影响点）。 参数：\code{data} 为数据框；\code{formula} 为模型公式（如 \code{y ~ x1 + x2}）； \code{bootstrap} 为重抽样次数（默认 0 即不计算自助法 CI）；\code{conf_level} 为置信水平，默认 0.95。 结果：返回列表——\code{coef}（系数表：估计/标准误/t 值/p 值/正态 CI，若开启 自助法另含 boot 下限/上限）、\code{performance}（R²/调整 R²/F 统计量/AIC/BIC）、 \code{vif}（各预测变量 VIF）、\code{diagnostics}（诊断用数据框）、 \code{diag_plots}（四张 ggplot 对象列表）、\code{plot}（残差诊断主图）。 注意：VIF 仅对数值型预测变量计算；自助法会显著增加运行时间，样本量很大时 建议先用少量（如 200）试探。本函数仅依赖基础 R 与 ggplot2，无需额外安装包。

示例代码 / Example

23. mc_wide_long

用途：把宽表（同一受试者的多次测量放在不同列）转换为长表（每次测量占一行），是数据处理的核心步骤。 方法（原创，原生实现）：先校验 id_cols 与 measure_vars 都存在于数据框；随后对每个测量列，将标识列按测量列数复制堆叠，并把测量列名作为「变量名」、对应取值作为「取值」逐列合并，输出整齐的长表。全程仅用 base R，无外部依赖。 参数：.data 为数据框；id_cols 为需保留的标识列（如 ID、分组）；measure_vars 为要拉长的测量列；name_to/value_to 分别为输出中「变量名」与「取值」列名，默认 variable / value。 结果：返回长格式数据框。 注意：转换后行数 = 原行数 × 测量列数；这是 mc_long_wide() 的逆操作。若测量列带有时间后缀（如 t1/t2/t3），转换后得到整齐的「时间-取值」两列，便于做重复测量分析。标识列为因子时会被保留为因子；测量列应类型一致，否则「取值」列会被强制转换为公共类型。

30. mc_model_compare

用途：在多个候选回归模型间做信息准则比较，选出相对最优者。 方法（自研）：AIC、BIC 取自基础 R；AICc = AIC + 2k(k+1)/(n-k-1)（k 为参数数、 n 为样本量，对样本量小于参数数+1 的模型记为 NA）；再计算 delta = AICc - min， Akaike 权重 w = exp(-0.5*delta) / sum(exp(-0.5*delta))，权重越大模型越优。 参数：\code{...} 为若干已拟合模型对象（如 lm/glm/coxph 等，需支持 \code{AIC()}/\code{BIC()}/\code{nobs()}）；\code{n} 为样本量（缺省时尝试用 \code{nobs()} 自动获取）。 结果：返回按权重降序排列的模型比较表，含 k（参数数）、n、AIC、BIC、AICc、 delta_AICc、weight。 注意：比较的模型必须基于同一数据集与同一响应变量，否则准则不可比。权重反映 各模型相对最优的概率，不表示绝对拟合优度。

示例代码 / Example

33. mc_competing_risk

用途：在存在「竞争事件」时做回归，避免把竞争事件误当作删失而高估目标事件风险。典型场景：研究死亡为竞争事件的复发分析。 方法：基于 cmprsk 包的 Fine-Gray 子分布风险模型（subdistribution hazard），将竞争事件作为特殊的删失处理，直接估计目标原因累积发生率。 参数：data 为数据框；time 为时间列；status 为状态列（0=删失，&gt;0 代表不同事件类型）；group 为分组/暴露变量；cause 指定关注的目标事件编号（默认 1）。 结果：返回列表，含 coefficients（各变量对应的子分布风险比 SHR、标准误、z、p 值）。 注意：status 的编码约定与 mc_survfit()/mc_cox() 不同：这里 0 才是删失，其它正整数各代表一类事件，务必按此约定整理数据。若仅有一个事件类型且无竞争，普通 Cox 即可。依赖 cmprsk（Suggests）。

34. mc_multistate

用途：拟合多状态生存模型，研究个体在多个健康状态间（如健康→并发症→死亡）的转移风险，比单一终点更贴近临床过程。 方法：基于 mstate 包，先把随访数据展开为「起点-终点」的转移长表，再用 coxph() 对每条转移分别建模。 参数：data 为已展开的多状态长表（含 id、Tstart、Tstop、status、from、to 等列）；trans 为转移矩阵（由 mstate::transMat() 构造，定义状态间允许哪些转移）；formula 含生存对象与协变量，可用 strata(trans) 对转移类型分层。 结果：返回列表，含 model（各转移的 coxph 拟合）、msfit（用于预测累积转移概率的 msfit 对象）。 注意：输入数据必须已是 mstate 要求的长表格式（非原始宽表），trans 的编号必须与 from/to 列及 strata(trans) 一致；构造错误会导致「所有观测同组」或无转移可估。依赖 mstate（Suggests）。

示例代码 / Example

# 第 8 章：三状态模型（健康 H -&gt; 并发症 I / 直接死亡 D）
set.seed(127)
library(mstate)
n &lt;- 150
age &lt;- rnorm(n, 55, 8)
t12 &lt;- rexp(n, .15); t23 &lt;- rexp(n, .20); t13 &lt;- rexp(n, .10)
rows &lt;- list()
for (i in 1:n) {
  if (runif(1) &lt; .6) {
    rows[[length(rows)+1]] &lt;- data.frame(id=i, Tstart=0,      Tstop=t12[i],        status=1, from=1, to=2, age=age[i])
    rows[[length(rows)+1]] &lt;- data.frame(id=i, Tstart=t12[i], Tstop=t12[i]+t23[i], status=1, from=2, to=3, age=age[i])
  } else {
    rows[[length(rows)+1]] &lt;- data.frame(id=i, Tstart=0, Tstop=t13[i], status=1, from=1, to=3, age=age[i])
  }
}
ms &lt;- do.call(rbind, rows)
trans &lt;- transMat(list(c(2,3), c(3), c()), names = c("H","I","D"))
ms$trans &lt;- with(ms, ifelse(from == 1 & to == 2, 1, ifelse(from == 1 & to == 3, 2, 3)))
fit &lt;- mc_multistate(ms, trans = trans, formula = survival::Surv(Tstart, Tstop, status) ~ age + strata(trans))
cat("coxph 系数 / coxph coefficients:\n")
print(summary(fit$model)$coefficients)
cat("\nmsfit 类别 / class:", class(fit$msfit)[1], "\n")
