macodgent: one simulated dataset for every analysis function

SIMULATED DATA — read this first

sim_htn_trial is entirely synthetic. It contains 3000 simulated hypertension-trial participants and 47 columns, generated by data-raw/sim_htn_trial.R with set.seed(20261105). There are no real patients, no real trial results and no personally identifiable information. Every example in this vignette, in the README and in every help page uses this one dataset. All estimates, p values and survival probabilities below are artefacts of the simulation; they must not be used for clinical, regulatory or epidemiological inference.

dim(d)
## [1] 3000   47
attr(d, "simulated")
## [1] TRUE
attr(d, "provenance")
## [1] "SYNTHETIC / SIMULATED data generated by data-raw/sim_htn_trial.R; no real patients; for package examples only; not for clinical or regulatory inference."

The dataset deliberately contains every variable role the package needs: continuous and skewed measurements, categorical and ordered factors, binary and ordinal endpoints, a time-to-event endpoint with a competing cause, repeated blood-pressure visits in wide format, matched case-control strata, and MCAR missing values. See ?sim_htn_trial for the full 47-column dictionary.
